I've always been interested in how AI models think and interact with each
other. Lately I've been building projects to find out, like a model that guesses
who painted a Renaissance painting and a tournament where AI models go head to
head.

### Tech stack

- **Languages:** Python, TypeScript, JavaScript, Java, SQL
- **Frontend:** React, Next.js, HTML, CSS
- **Backend and data:** Cloudflare Workers, SQLite, MySQL, Drizzle ORM
- **Machine learning:** PyTorch, scikit-learn
- **Tools:** Git, GitHub Actions, Docker, Playwright, Maven

## Featured projects

- **Renart**: guesses which Renaissance painter made a painting, right 78% of the time. [See the results](https://kennethkimbrough.github.io/Renart/)
- **tit-for-token**: AI models play the prisoner's dilemma against each other. [See the results](https://kennethkimbrough.github.io/tit-for-token/)
- **Outage Ready**: shows how long your home can last in a power or water outage. [Try it](https://kennethkimbrough.github.io/outage-ready/)
- **Biscuit's Bowls**: a cat café puzzle game coming to iPhone. [How the multiplayer works](https://github.com/kennethkimbrough/kennethkimbrough/blob/main/biscuits-bowls-multiplayer.md)
